Why voice and caller ID no longer prove identity

Telephone networks authenticate signaling trunks, not the person speaking or their mandate inside a company. Customers need proof independent of the phone call itself.

  1. 01

    Company impersonation and number spoofing

    Fraudsters display legitimate bank or support phone numbers while social-engineering credentials or one-time passcodes.

  2. 02

    Real-time voice cloning and deepfake audio

    Seconds of public speech can be synthesized into a familiar executive or support voice that passes casual human listening.

  3. 03

    Unverified employee scope and stale access

    Customers have no way to check whether a caller is still employed, currently active, or authorized to initiate a high-risk request.

Security controls and honest boundaries

Every guarantee is enforced server-side in FastAPI and SQLite, with explicit boundaries documented up front.

Argon2id and SHA-256 token storage

Passwords are salted and hashed with Argon2id. Issued Trust IDs and anonymous customer session keys are stored strictly as SHA-256 digests.

Atomic single-use redemption

Public Trust ID lookup runs a conditional SQLite update as the first write statement so concurrent requests cannot redeem the same code twice.

Zero raw audio persistence

Browser MediaRecorder clips are validated for MIME type and size in memory during enrollment and pre-call checks, never stored in the database.

Zero-account verification and escalation

Customers verify calls without registering, keep viewing access via an HttpOnly cookie across page reloads, and can flag suspicious calls directly to admins.

MVP Transparency Notice: The Trust Layer is a pre-call verification and authorization platform. It does not intercept live cellular or PSTN carrier audio streams. Company verification reflects platform-admin review, employee identity is company-attested, and when AI_PROVIDER=mock is active, Layer 3 outputs deterministic simulation scores labeled DEMO MODE rather than real acoustic analysis.
